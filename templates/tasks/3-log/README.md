# 3-log · timeline log

> **Append only.** This records what happened, not what to do. Todos are state, logs
> are a stream; mixing them means manual reshuffling later.
> This directory **is not scanned**, so nothing here reaches the board.

One file per week (`2026-W43.md`) or per month (`2026-10/`) works well:

```markdown
# 2026-W43

## Done

- 10-21 Switched the review to a two-week cycle; try it for two rounds

## Stuck on

- Report three export: waiting for the field list to be confirmed

## Next week

- Book the check-up (10-28)
```
